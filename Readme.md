## 세계관

주인공은 산 채로 **저승 서커스**에 납치되어 노동과 학대를 당한다. 극장 주인 **"마스터"**가 이 서커스를 운영한다.

- **가면** — 저승 존재들은 이승 사람들에게 잊혀졌기에 가면을 쓰고 다닌다. 주인공도 쓰고 있으며 벗을 수 있다.
- **자아 소멸** — 저승에 오래 머물면 자아가 옅어지다 혼 자체가 소멸한다. 소멸 직전의 존재들이 게임 속 적(악귀)으로 등장한다.
- **기억 조각** — 백지 상태의 조각. 영혼이 접촉하면 그 기억이 실체화되어 담기고, 다른 사람이 접촉하면 그 기억을 엿볼 수 있다. 잊혀진 망자가 닿으면 먹물을 먹은 듯 오염되어 기억을 담지 못한다.
- **거울** — 기억 조각으로 만들어져 자신의 모습을 저장한다(세이브포인트). 조각을 다 모으면 거울이 완성되어 이승 또는 저승으로 넘어갈 수 있다.
- **저승 도시 공기** — 이승에서 온 존재에게만 해로운 탁한 공기. **"팥"**을 먹으면 회복된다 (팥을 뿌리면 귀신이 사라진다는 한국 설화에서 착안).

주인공은 처음에 아무 스킬도 없다. 스토리를 진행하며 같은 단원들에게 하나씩 전수받는다.

## 스토리

전체 목표는 **저승 탈출**이다.

```
챕터1 서커스 극장 → 챕터2 저승 도시 → 챕터3 지하감옥 → 챕터4 무대(보스전) → 엔딩
```


| 챕터     | 배경          | 내용                                                                                                              |
| ------ | ----------- | --------------------------------------------------------------------------------------------------------------- |
| **1**  | 서커스 극장 / 숙소 | 강제로 시작된 첫 공연에서 실패하고 마스터의 폭력을 겪는다. 매니저에게 "여기는 저승"이라는 사실과 기억 조각·거울에 대한 정보를 듣는다. 탈출을 제안하지만 단원들은 과거의 보복 트라우마로 거절한다. |
| **2**  | 저승 도시 (지상)  | 폐허구역에서 자아를 잃은 망자들과 전투하고, 도시구역에서는 퍼즐과 부탁 수행으로 조각을 모은다. 순찰 망자에게 쫓기는 추격 구간 끝에 하수구가 지하감옥과 연결된다는 정보를 얻는다.            |
| **3**  | 서커스 지하감옥    | 함께 갇힌 동료와 탈출을 시도하며 **기억 추출 장치**를 발견한다. 소멸 직전인 동료의 기억 조각을 찾아 회생시키고 함께 탈출한다.                                      |
| **4**  | 서커스 내부 · 무대 | 마스터실에서 단원들의 기억이 저장된 것을 보고 충격받은 직후 기습당한다. 관객들이 지켜보는 무대에서 마스터와 최종 결전을 벌이고, 마지막 큰 기억 조각을 얻는다.                      |
| **엔딩** | —           | 완성된 거울 앞에서 **이승으로 돌아갈지 / 저승에 남을지** 선택한다.                                                                        |

## 스킬

주인공은 스토리를 진행하며 단원들에게 특기를 전수받는다. **최대 3개까지 동시 장착**하며 취향대로 조합할 수 있고, 거울 앞에서 `[E]`로 정비 창을 열어 교체한다. 기억 조각을 일정량 모으면 스킬 포인트로 전환되어 업그레이드할 수 있다.

## 게임 시스템

### 자아 게이지 (체력)

0이 되면 게임오버. 망령에게 공격받으면 감소하고, 기억 조각을 먹거나 거울에서 회복할 수 있다.

### 오염도 게이지 (챕터2~)

최대 100. 시간이 지나며 자동으로 누적되고 챕터가 진행될수록 증가 속도가 빨라진다. 다 차면 사망하며, **"팥"** 섭취 시 0으로 초기화된다.

### 기억 조각

게임의 핵심 수집 재화. **회복 아이템 겸 스킬 포인트 재료**로 쓰인다.

획득 방법은 ① 조작으로 직접 획득 ② 퍼즐 풀이 ③ 리스크형(마스터의 방 잠입 등) ④ NPC와의 교류 4가지다.


| 챕터  | 목표 수량                  |
| --- | ---------------------- |
| 챕터1 | 10개                    |
| 챕터2 | 20개                    |
| 챕터4 | 큰 기억 조각 1개 (마스터 처치 보상) |


### 아이템


| 분류  | 이름       | 효과                                         |
| --- | -------- | ------------------------------------------ |
| 회복  | 작은 기억 조각 | 체력 30 회복                                   |
| 회복  | 큰 기억 조각  | 체력 60 회복. 일정량 모으면 스킬 포인트로 전환               |
| 기믹성 | 팥        | 오염도를 0으로 초기화                               |
| 저주  | 오염된 거울   | 망령 처치 시 드롭. 정화하지 않고 쓰면 오염도가 오르지만 체력은 일부 회복 |

## 기술 구조

- **Unity 6000.4.6f1** / Universal Render Pipeline / 2D
- 입력: Input System · 카메라: Cinemachine
- 폰트: SCDream6 한글 TMP SDF (한글 음절 11,172자, Git LFS 추적)
- 비동기 처리는 전부 **코루틴** (async/await · UniTask · DOTween 미사용)
- 빌드·테스트는 전부 Unity Editor에서 수행

프로젝트 코드와 에셋은 전부 `Assets/_Project/` 안에 있다.

```
Scripts/
  _Player/      플레이어 주체 (Camera/ · Combat/ · Move/ · Skill/)
  Monster/      몬스터 주체
  Character/    플레이어·몬스터 공용 (Health · HitReactor · HitFlash · HealthBar · MoveSystem)
  Combat/       전투 연출 싱글턴 (HitFeedback · HitVfx · DamagePopup)
  Interaction/  상호작용 (IInteractable · PlayerInteractor · SaveMirror)
  Objective/    목표(퀘스트)
  Story/        대사 · 컷씬
  Ui/           메뉴 · 설정 UI
  System/       게임 전역
  _Data/        세이브 데이터
```

### 전투 파이프라인

`Health`가 이벤트 허브 역할을 한다.

```
Player_Combat.DealDamage()
  → Health.TakeDamage(damage, sourcePosition)
      → OnDamaged  ─┬→ HitReactor  넉백 · 히트스파크 · 데미지 팝업 · 쉐이크/히트스톱
                    ├→ HitFlash    피격자 플래시/스쿼시
                    └→ HealthBar
      → OnDeath    ─→ HitReactor  사망 연출
```

### 씬 흐름

```
BootScene / Main_menu → CoreScene (인게임 본편)
```

### 세이브

`SaveManager`가 파일 입출력과 상태 수집·복원을 담당한다. 저장 위치는 `Application.persistentDataPath/save.json`, 직렬화는 `JsonUtility`. 정식 저장 지점은 **거울(`SaveMirror`)** 이며 `F5`/`F9`는 개발용 퀵세이브 단축키다.
